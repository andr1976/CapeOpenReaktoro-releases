Reaktoro e-NRTL CESAR-1 property package

A free CAPE-OPEN 1.1 property package for the CESAR-1 solvent (aqueous AMP and piperazine) for CO2 capture, based on the electrolyte NRTL model and built on Reaktoro. Portable, per-user install for Windows x64.

What it is

  • One CAPE-OPEN 1.1 property package, Reaktoro eNRTL (AMP-PZ-CO2-H2O), with the compounds H2O, CO2, AMP, PZ, N2 and O2 (N2 and O2 as Henry-law inerts).
  • Vapour-liquid equilibrium, enthalpy, density, viscosity and surface tension of the CESAR-1 solvent with published parameters, for absorber and desorber simulation.
  • Example COFE flowsheets: absorber, absorber with desorber, lean vapour compression and pilot-plant cases.

Install

  1. Extract the ZIP to a permanent folder, e.g. C:\ReaktoroCO-CESAR1.
  2. Close the simulator and run Install.bat (per user, no administrator rights; run it again if you move the folder).
  3. Optional: Test-Package.ps1 checks the installation without a simulator.
  4. Select Reaktoro eNRTL (AMP-PZ-CO2-H2O) in the simulator.

To uninstall, run Uninstall.bat and delete the folder.

Prerequisites

  • Windows 10/11 x64 with .NET Framework 4.8
  • Microsoft Visual C++ 2015-2022 x64 runtime
  • A 64-bit CAPE-OPEN 1.1 simulator, e.g. COCO/COFE with ChemSep
